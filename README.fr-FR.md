## À propos de ViviResume

Choisissez un modèle professionnel, ajoutez votre parcours et suivez le résultat en temps réel. Conservez le brouillon dans ce navigateur ou enregistrez-le dans le cloud pour le partager par lien.

![ViviResume](asset/viviresume-og.png)

## Créez votre CV en trois étapes

Choisissez un modèle, présentez votre parcours, puis enregistrez, partagez ou téléchargez le résultat.

### 1. Choisissez un modèle

Comparez les mises en page et choisissez la structure et le style qui mettent le mieux votre contenu en valeur.

### 2. Ajoutez votre parcours professionnel

Remplacez les exemples, organisez vos rubriques et peaufinez la page en vous appuyant sur l’aperçu en temps réel.

### 3. Enregistrer, partager ou télécharger

Examinez la page terminée, puis enregistrez votre CV dans le cloud, partagez-le par lien ou téléchargez-le au format PDF, DOCX, DOC ou Markdown.

## Conditions d’utilisation

L’enregistrement dans le cloud et le partage par lien nécessitent une connexion au compte. Les brouillons du navigateur restent sur cet appareil.

### Des rubriques selon vos besoins

Ajoutez vos expériences, votre formation, vos projets, vos compétences, vos langues, vos certificats, votre profil et des rubriques personnalisées. Mettez les descriptions en forme et ajoutez une photo ou des images de certificats si nécessaire.

### Personnalisez la mise en page

Réglez les polices, les couleurs, la taille et l’interligne, les marges, l’espacement des rubriques, l’échelle du contenu et l’ajustement automatique sur une page.

## Questions fréquemment posées

### Puis-je conserver mon CV dans ce navigateur ou l’enregistrer dans le cloud ?

Oui. Votre brouillon est enregistré dans ce navigateur au fur et à mesure que vous le modifiez. Lorsque vous choisissez Enregistrer dans le cloud, ViviResume crée ou met à jour la version en ligne. Les modifications ultérieures restent dans ce navigateur jusqu’à ce que vous les enregistriez à nouveau dans le cloud.

### Où est enregistré le brouillon dans ce navigateur ?

Votre brouillon est conservé dans ce navigateur, sur cet appareil. Il ne sera pas disponible sur un autre appareil et peut disparaître si vous effacez les données du navigateur. Enregistrez-le dans le cloud lorsque vous souhaitez disposer d’une version en ligne.

### Qui peut consulter un CV partagé ?

Après avoir enregistré votre CV dans le cloud, activez le partage pour créer un lien. Toute personne disposant du lien peut consulter le CV. Vous pouvez désactiver le partage, créer un nouveau lien et choisir si les visiteurs peuvent télécharger un PDF.

### Quels formats de téléchargement sont disponibles ?

Vous pouvez télécharger votre CV au format PDF, DOCX, DOC ou Markdown. Le PDF reprend la mise en page affichée ; Word et Markdown permettent de retravailler le contenu par la suite.

### Quelles versions en langues régionales sont disponibles ?

ViviResume propose des interfaces, des modèles et des exemples adaptés à 25 versions régionales couvrant 22 langues. Changer la langue de l’interface ne traduit pas le contenu déjà saisi dans votre CV.

### Puis-je transférer un brouillon existant vers un autre modèle ?

Pas encore. Pour utiliser un autre modèle, créez un nouveau brouillon à partir de celui-ci et recopiez manuellement le contenu à conserver. Votre brouillon actuel restera inchangé.

## 關於 ViviResume

選擇專業範本、填寫你的經歷，並即時查看版面效果。草稿可以儲存在此瀏覽器，也可以儲存到雲端並透過連結分享。

![ViviResume](asset/viviresume-og.png)

## 三步完成一份履歷

選擇範本、填寫經歷，再儲存、分享或下載完成的履歷。

### 1. 選擇一套範本

比較不同版面，選擇更能承載你的內容結構與視覺風格。

### 2. 填寫你的經歷

替換範例內容、整理區塊順序，並在即時預覽中逐步調整頁面。

### 3. 儲存、分享或下載

檢查最終頁面後，可以儲存到雲端、分享連結，或下載 PDF、DOCX、DOC 與 Markdown。

## 使用條件

儲存雲端版本和開啟分享連結需要登入；瀏覽器草稿保存在目前裝置。

### 彈性的內容區塊

依需要加入工作經歷、教育經歷、專案經歷、技能、語言、證書、個人簡介與自訂區塊；描述可使用粗體、清單等格式，也可以加入個人照片或證書圖片。

### 細緻的外觀設定

調整字型、顏色、字級、行高、頁面邊界、區塊間距、內容縮放與自動單頁調整等版面細節。

## 常見問題

### 履歷可以只儲存在目前瀏覽器中，也可以儲存到雲端嗎？

可以。編輯時，草稿會儲存在目前的瀏覽器。選擇「儲存到雲端」後，ViviResume 會建立或更新雲端履歷；之後的修改會在你再次儲存時更新到雲端。

### 目前瀏覽器中的草稿儲存在哪裡？

草稿會儲存在目前裝置的這個瀏覽器中，不會出現在其他裝置上；清除瀏覽器資料可能會將其刪除。需要線上版本時，可以把履歷儲存到雲端。

### 誰能透過分享連結查看履歷？

把履歷儲存到雲端後，可以開啟分享並建立連結。任何取得連結的人都能查看這份履歷；你可以隨時關閉分享或更換連結，也可以決定是否允許訪客下載 PDF。

### 可以下載哪些格式？

可以下載 PDF、DOCX、DOC 或 Markdown。PDF 對應頁面的視覺預覽，Word 與 Markdown 則提供可繼續編輯的內容，適合不同的後續處理方式。

### 提供哪些地區語言版本？

ViviResume 提供涵蓋 22 種語言的 25 個地區版本，包含對應的介面、範本與範例。切換網站地區語言不會自動翻譯你已填寫的內容。

### 既有草稿可以直接切換範本嗎？

目前的編輯器無法直接切換。若要使用另一套範本，請從該範本建立新草稿，再手動移入需要保留的內容；既有草稿不會被修改。

## Über ViviResume

Wählen Sie eine professionelle Vorlage, tragen Sie Ihren beruflichen Werdegang ein und verfolgen Sie das Ergebnis in Echtzeit. Behalten Sie den Entwurf in diesem Browser oder speichern Sie ihn in der Cloud und teilen Sie ihn per Link.

![ViviResume](asset/viviresume-og.png)

## Erstellen Sie Ihren Lebenslauf in drei Schritten

Wählen Sie eine Vorlage, tragen Sie Ihren Werdegang ein und speichern, teilen oder laden Sie das Ergebnis anschließend herunter.

### 1. Wählen Sie eine Vorlage

Vergleichen Sie Layouts und wählen Sie die Struktur und den Stil, die Ihre Inhalte am besten zur Geltung bringen.

### 2. Beruflichen Werdegang eintragen

Ersetzen Sie die Beispieldaten durch Ihre eigenen, ordnen Sie die Abschnitte und stimmen Sie die Seite anhand der Vorschau in Echtzeit ab.

### 3. Speichern, teilen oder herunterladen

Überprüfen Sie die fertige Seite, speichern Sie sie dann in der Cloud, teilen Sie einen Link oder laden Sie PDF, DOCX, DOC oder Markdown herunter.

## Nutzungshinweise

Cloud-Speicherung und Linkfreigabe erfordern eine Anmeldung. Browserentwürfe bleiben auf diesem Gerät.

### Flexible Lebenslaufabschnitte

Fügen Sie Berufserfahrung, Ausbildung, Projekte, Kenntnisse, Sprachen, Zertifikate, ein Kurzprofil und eigene Abschnitte hinzu. Formatieren Sie Details und ergänzen Sie bei Bedarf ein Profilfoto oder Abbildungen von Zertifikaten.

### Umfangreiche Design-Einstellungen

Passen Sie Schriftarten, Farben, Textgröße, Zeilenabstand, Seitenränder, Abschnittsabstände und die Inhaltsskalierung an. Bei Bedarf lässt sich der Lebenslauf automatisch auf eine Seite einpassen.

## Häufig gestellte Fragen

### Kann ich meinen Lebenslauf in diesem Browser behalten oder in der Cloud speichern?

Ja. Ihr Entwurf wird während der Bearbeitung in diesem Browser gespeichert. Wenn Sie „In Cloud speichern“ wählen, erstellt oder aktualisiert ViviResume die Online-Version. Spätere Änderungen bleiben in diesem Browser, bis Sie sie erneut in der Cloud speichern.

### Wo wird der Entwurf in diesem Browser gespeichert?

Ihr Entwurf wird in diesem Browser auf diesem Gerät gespeichert. Auf anderen Geräten ist er nicht verfügbar und beim Löschen der Browserdaten kann er verloren gehen. Speichern Sie ihn in der Cloud, wenn Sie eine Online-Version benötigen.

### Wer kann einen geteilten Lebenslauf einsehen?

Nachdem Sie Ihren Lebenslauf in der Cloud gespeichert haben, aktivieren Sie die Freigabe, um einen Link zu erstellen. Jeder, der über den Link verfügt, kann den Lebenslauf einsehen. Sie können die Freigabe deaktivieren, einen neuen Link erstellen und auswählen, ob Besucher ein PDF herunterladen dürfen.

### Welche Downloadformate stehen zur Verfügung?

Sie können Ihren Lebenslauf als PDF, DOCX, DOC oder Markdown herunterladen. Das PDF übernimmt das angezeigte Seitenlayout; Word und Markdown eignen sich zur weiteren Bearbeitung der Inhalte.

### Welche regionalen Sprachversionen sind verfügbar?

ViviResume bietet Benutzeroberflächen, Vorlagen und Beispiele in 25 regionalen Versionen für 22 Sprachen. Wenn Sie die Sprache der Oberfläche wechseln, werden bereits eingegebene Lebenslauftexte nicht automatisch übersetzt.

### Kann ich einen vorhandenen Entwurf auf eine andere Vorlage umstellen?

Derzeit noch nicht. Erstellen Sie für eine andere Vorlage einen neuen Entwurf und übertragen Sie die gewünschten Inhalte manuell. Ihr bisheriger Entwurf bleibt unverändert.

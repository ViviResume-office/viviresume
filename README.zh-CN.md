## 关于 ViviResume

选择专业模板，填写你的经历，并实时查看排版效果。草稿可以保存在此浏览器，也可以保存到云端并通过链接分享。

![ViviResume](asset/viviresume-og.png)

## 三步完成一份简历

选择模板、填写经历，再保存、分享或下载完成的简历。

### 1. 选择一套模板

比较不同版式，选择更能承载你的内容结构和视觉风格。

### 2. 填写你的经历

替换示例内容、整理版块顺序，并在实时预览中逐步调整页面。

### 3. 保存、分享或下载

检查最终页面后，可以保存到云端、分享链接，或下载 PDF、DOCX、DOC 与 Markdown。

## 使用条件

保存云端版本和开启分享链接需要登录；浏览器草稿保存在当前设备。

### 按需添加简历版块

按需添加工作经历、教育经历、项目经历、技能、语言、证书、个人简介和自定义版块；描述可设置加粗、列表等格式，也可以加入个人照片或证书图片。

### 细致的外观设置

调整字体、颜色、字号、行高、页边距、版块间距、内容缩放与自动单页适配等页面细节。

## 常见问题

### 简历可以只保存在当前浏览器中，也可以保存到云端吗？

可以。编辑时，草稿会保存在当前浏览器。选择“保存到云端”后，ViviResume 会创建或更新云端简历；之后的修改会在你再次保存时更新到云端。

### 当前浏览器中的草稿保存在哪里？

草稿会保存在当前设备的这个浏览器中，不会出现在其他设备上；清除浏览器数据可能会将其删除。需要在线版本时，可以把简历保存到云端。

### 谁能通过分享链接查看简历？

把简历保存到云端后，可以开启分享并生成链接。任何获得链接的人都能查看这份简历；你可以随时关闭分享或更换链接，也可以决定是否允许访客下载 PDF。

### 可以下载哪些格式？

可以下载 PDF、DOCX、DOC 或 Markdown。PDF 对应页面的视觉预览，Word 和 Markdown 则提供可继续编辑的内容，适合不同的后续处理方式。

### 提供哪些地区语言版本？

ViviResume 提供覆盖 22 种语言的 25 个地区版本，包含对应的界面、模板和示例。切换网站地区语言不会自动翻译你已经填写的内容。

### 已有草稿可以直接切换模板吗？

当前编辑器不能直接切换。若要使用另一套模板，请从该模板创建新草稿，再手动移入需要保留的内容；原有草稿不会被修改。

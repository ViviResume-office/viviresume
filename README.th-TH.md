## เกี่ยวกับ ViviResume

เลือกเทมเพลตมืออาชีพ เพิ่มประสบการณ์ และดูเรซูเม่ที่เสร็จสมบูรณ์แบบเรียลไทม์ เก็บฉบับร่างไว้ในเบราว์เซอร์นี้ หรือบันทึกขึ้นคลาวด์แล้วแชร์ผ่านลิงก์

![ViviResume](asset/viviresume-og.png)

## สร้างเรซูเม่ใน 3 ขั้นตอน

เลือกเทมเพลต เพิ่มประสบการณ์ แล้วบันทึก แชร์ หรือดาวน์โหลดเรซูเม่

### 1. เลือกเทมเพลต

เปรียบเทียบเลย์เอาต์ แล้วเลือกโครงสร้างและดีไซน์ที่นำเสนอประสบการณ์ของคุณได้ดีที่สุด

### 2. เพิ่มประสบการณ์ทำงาน

แทนที่ข้อมูลตัวอย่างด้วยข้อมูลจริงของคุณ จัดลำดับหัวข้อ และปรับหน้าให้เรียบร้อยพร้อมดูตัวอย่างแบบเรียลไทม์

### 3. บันทึก แชร์ หรือดาวน์โหลด

ตรวจสอบหน้าที่เสร็จแล้ว จากนั้นบันทึกขึ้นคลาวด์ แชร์ลิงก์ หรือดาวน์โหลด PDF, DOCX, DOC หรือ Markdown

## เงื่อนไขการใช้งาน

การบันทึกบนคลาวด์และการแชร์ลิงก์ต้องเข้าสู่ระบบ แบบร่างในเบราว์เซอร์จะอยู่บนอุปกรณ์นี้

### เพิ่มหัวข้อได้ตามต้องการ

เพิ่มประสบการณ์ การศึกษา โปรเจกต์ ทักษะ ภาษา ใบรับรอง สรุปโปรไฟล์ และหัวข้อที่กำหนดเองได้ จัดรูปแบบคำอธิบาย พร้อมใส่รูปโปรไฟล์หรือภาพใบรับรองเมื่อจำเป็น

### ปรับหน้าตาได้อย่างละเอียด

ปรับแบบอักษร สี ขนาดตัวอักษร ระยะห่างระหว่างบรรทัด ขอบกระดาษ ระยะห่างระหว่างหัวข้อ และสัดส่วนเนื้อหา หรือให้ระบบปรับเรซูเม่ให้พอดีหนึ่งหน้าโดยอัตโนมัติ

## คำถามที่พบบ่อย

### ฉันเก็บเรซูเม่ไว้ในเบราว์เซอร์นี้หรือบันทึกขึ้นคลาวด์ได้หรือไม่

ใช่ ฉบับร่างของคุณจะถูกบันทึกไว้ในเบราว์เซอร์นี้เมื่อคุณแก้ไข เมื่อคุณเลือกบันทึกขึ้นคลาวด์ ViviResume จะสร้างหรืออัปเดตเวอร์ชันออนไลน์ การแก้ไขในภายหลังจะยังคงอยู่ในเบราว์เซอร์นี้จนกว่าคุณจะบันทึกขึ้นคลาวด์อีกครั้ง

### ฉบับร่างในเบราว์เซอร์นี้บันทึกไว้ที่ไหน

ระบบจะเก็บฉบับร่างไว้ในเบราว์เซอร์ของอุปกรณ์นี้เท่านั้น ฉบับร่างจะไม่ปรากฏบนอุปกรณ์อื่นและอาจถูกลบเมื่อล้างข้อมูลเบราว์เซอร์ หากต้องการเวอร์ชันออนไลน์ ให้บันทึกเรซูเม่ขึ้นคลาวด์

### ใครสามารถดูเรซูเม่ที่แชร์ได้บ้าง

หลังจากบันทึกเรซูเม่ขึ้นคลาวด์แล้ว ให้เปิดการแชร์เพื่อสร้างลิงก์ ทุกคนที่มีลิงก์สามารถดูเรซูเม่ได้ คุณสามารถปิดการแชร์ สร้างลิงก์ใหม่ และกำหนดว่าจะอนุญาตให้ดาวน์โหลด PDF หรือไม่

### มีรูปแบบการดาวน์โหลดใดบ้าง?

คุณดาวน์โหลดเรซูเม่เป็น PDF, DOCX, DOC หรือ Markdown ได้ โดย PDF จะคงรูปแบบตามหน้าตัวอย่าง ส่วนไฟล์ Word และ Markdown เหมาะสำหรับนำไปแก้ไขต่อ

### รองรับภาษาและภูมิภาคใดบ้าง?

ViviResume มีอินเทอร์เฟซ เทมเพลต และตัวอย่างสำหรับ 25 เวอร์ชันภูมิภาค ครอบคลุม 22 ภาษา การเปลี่ยนภาษาของอินเทอร์เฟซจะไม่แปลข้อความที่กรอกไว้ในเรซูเม่โดยอัตโนมัติ

### ย้ายฉบับร่างเดิมไปใช้เทมเพลตอื่นได้ไหม

ขณะนี้ยังทำไม่ได้ หากต้องการใช้เทมเพลตอื่น ให้สร้างฉบับร่างใหม่จากเทมเพลตนั้น แล้วคัดลอกเนื้อหาที่ต้องการเก็บไว้ด้วยตนเอง ฉบับร่างเดิมจะไม่เปลี่ยนแปลง
